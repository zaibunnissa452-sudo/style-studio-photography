# Style Studio Photography

Standalone React and Vite website for Style Studio Photography in Hyderabad. This repository contains photography pages, their components and styles, and only the images used by the photography site. Smart Canteen files are not included.

## Start locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The homepage is the photography experience. Saleem's portrait remains the center of the orbit hero, with event photographs revolving around it.
